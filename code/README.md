## 一、环境准备

只需要一个 C++ 编译器。

### Windows

**方案 A：Dev-C++（最简单）**
1. 下载安装 [Dev-C++](https://sourceforge.net/projects/orwelldevcpp/)
2. 打开 `.cpp` 文件，按 `F11` 编译运行

**方案 B：MinGW + VS Code（更专业）**
1. 安装 [MinGW-w64](https://www.mingw-w64.org/)
2. 安装 VS Code + `C/C++` 扩展
3. 验证：命令行输入 `g++ --version`，看到版本号即成功

### 验证编译环境

```bash
g++ --version
# 应输出类似：g++ (Rev6, Built by MSYS2 project) 16.1.0
```

## 二、编译运行

**所有代码都用 g++ 编译**（C++ 文件，有的用到 C++11 特性）：

```bash
# 进入本目录
cd 数据结构与算法_自学笔记/code

# 编译单个文件
g++ -std=c++11 02_单链表.cpp -o demo

# 运行（Windows Git Bash / Linux / macOS）
./demo

# Windows CMD 下运行
demo.exe

# 一条命令搞定编译+运行
g++ -std=c++11 02_单链表.cpp -o demo && ./demo
```

### 推荐编译参数

```bash
g++ -std=c++11 -Wall -O2 文件名.cpp -o demo
```

| 参数 | 作用 |
|---|---|
| `-std=c++11` | 使用 C++11 标准（部分代码用了 auto、范围 for 等特性） |
| `-Wall` | 打开所有警告（帮你发现潜在问题） |
| `-O2` | 优化（性能测试类代码建议加） |

> **注意**：`07_排序综合对比.cpp` 涉及大规模数据测试，**建议加 `-O2`**，否则会跑很久。

## 四、建议的学习方式

**不要只是编译运行看结果！** 建议这样做：

1. **先读笔记**，理解算法思路
2. **在纸上手算一遍**（用笔记里的小例子）
3. **自己敲一遍代码**（不要复制粘贴！）
4. **对照本目录的代码**，看哪里不一样
5. **修改代码做实验**：
   - 改变数据规模，观察性能变化
   - 把 `>` 改成 `>=`，看稳定性是否改变
   - 打乱输入顺序，看算法是否退化

## 五、常见编译问题

| 报错 | 原因 | 解决 |
|---|---|---|
| `'auto' not allowed here` | 没用 C++11 | 加 `-std=c++11` |
| `'xxx' was not declared` | 缺头文件 | 检查 `#include` |
| `undefined reference to 'main'` | 没有 main 函数 | 检查文件是否完整 |
| 中文输出乱码 | 编码问题 | Windows CMD 执行 `chcp 65001`，或用 Git Bash |
| `[Error] ld returned 1 exit status` | 上次的程序还在运行 | 关掉上次的运行窗口 |

### 中文乱码解决

Windows 命令行默认是 GBK 编码，而源文件是 UTF-8。解决方法：

**方法 1：用 Git Bash**（推荐，默认 UTF-8）

**方法 2：CMD 里先切换编码**
```cmd
chcp 65001
demo.exe
```

**方法 3：VS Code 里设置终端编码**
