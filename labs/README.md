# 💻 手写代码实战训练场（`labs/`）

> **为什么需要这个训练场？**
>
> 很多同学学数据结构都有同一个痛点：**笔记看懂了，图也画明白了，可一打开空白编辑器还是写不出代码**。
> 本训练场把全书 **第 0～7 章 + 进阶专题 + 终极盲写大考** 拆成 **15 个循序渐进的手写关卡**。每个关卡都有：
> - **`labXX_todo.cpp`**：你的实战文件（纯 `int` + `struct` 基础风格，去掉 `template` 和异常语法干扰，每个函数上方都写好了「画图 + 中文步骤 + 边界提醒」，只把核心逻辑挖空等你填）
> - **`labXX_solution.cpp`**：完整参考答案（卡住超过 15 分钟再看，切忌先看答案再抄）
> - **智能一键评测脚本 `judge.py`**：支持编译运行评测、**可视化学习进度看板（`--progress`）**、**不剧透推导提示（`--hint`）** 和 **环境一键自检（`--check-env`）**！

## 一、快速开始（1 分钟跑通）

打开终端（PowerShell / CMD / VS Code 终端 / Git Bash），进入 `labs` 目录：

```powershell
cd C:\数据结构\数据结构与算法_自学笔记\labs
```

### 常用命令

```powershell
# 0. 首次使用先一键检测 g++ / C++11 / Python 环境
python judge.py --check-env

# 1. 查看全部 15 个关卡编号与说明
python judge.py --list

# 2. 查看你的实时学习进度看板（可视化进度条 + 自动推荐下一关）
python judge.py --progress

# 3. 只评测某一关（推荐！写完一关测一关，比如第 00 关指针热身）
python judge.py 00

# 4. 卡住了但不想直接看答案？查看“不剧透”推导提示卡片
python judge.py --hint 03

# 5. 一次评测多关（比如第 2 章全部三关）
python judge.py 02 03 04

# 6. 评测全部 15 关
python judge.py all

# 7. 验证参考答案与评测环境是否正常（全绿说明你的编译器和环境完全没问题）
python judge.py --solution all
```

> **Windows 快捷方式**：也可以直接在终端里运行 `.\run_judge.bat 03` 或双击 `run_judge.bat` 查看关卡列表。
>
> **也可以不用 Python，直接用 `g++` 单文件编译**：
> ```powershell
> g++ -std=c++11 -Icommon 03_单链表手写/lab03_todo.cpp -o lab03.exe && .\lab03.exe
> ```

## 三、高效闯关五步法（别跳步！）

1. **先读对应章节笔记**，重点读完该章新增的「💻 手写代码实战工坊」。
2. **打开 `labXX_todo.cpp`**，先跑一次 `python judge.py XX`，看看所有测试用例长什么样（初始会全部 FAIL，这是正常的）。
3. **一次只写一个函数**！先读函数上方注释的「画图与思路推导」，在草稿纸上画一遍指针/下标变化，再填进 `// TODO` 区域。
4. **每写完一个函数就立刻跑 `python judge.py XX`**——看到 `[FAIL]` 变成 `[PASS]` 就是最强的正反馈！如果某个边界用例没过，按终端里的 `排查提示` 逐行检查。
5. **全绿通关后做一次「合书复盘」**：把你写的代码删掉关键函数，隔天不看注释默写一遍，能再次全绿才算真正拿下！

## 四、常见运行报错急救

| 终端提示 | 最可能的原因 | 怎么办 |
|---|---|---|
| `[编译失败]` 提示 `expected ';'` / `was not declared` | 少分号、拼错变量名、括号没配对 | 看编译器报的**第一条**错误的行号，顺着往上查 1～2 行 |
| `[运行超时 >8s]` | **死循环！** | 检查 `while` 里指针有没有 `p = p->next`、循环条件是否永远为真、链表是不是不小心连成了环、快排全相等数组时 `i/j` 有没有停住 |
| `[异常崩溃]` (返回码非 0/1) | **空指针解引用 / 数组越界 / 无限递归栈溢出** | 在 `p->next` 前先检查 `p != nullptr`；检查数组下标是否 `< 0` 或 `>= n`；检查递归函数第一行有没有出口 |
| 某条 `[FAIL]` 差 1 | **位序(从1) vs 下标(从0)** 混了，或 `<` 写成了 `<=` | 用 2～3 个元素的极小例子在纸上一步步手算 |
