## 一、这套笔记怎么用（先读这 3 分钟）

### 1. 你不需要很聪明，但需要按顺序来

数据结构最怕"跳着学"。第 4 章的二叉树要用到第 2 章的指针和第 3 章的递归；第 5 章的图要用到第 3 章的队列。所以：

```
第0章 基础回顾  →  第1章 绪论  →  第2章 线性表  →  第3章 扩展  →  第4章 树  →  第5章 图  →  第6章 查找  →  第7章 排序
   （必读）        （打地基）      （核心！）      （核心！）     （难点）     （难点）     （应用）      （应用）
```

**唯一可以跳过的**：如果你已经写过 C/C++ 代码、懂指针，第 0 章可以只扫一眼。

### 2. 每一节的固定结构（看到这些标题你就知道要干嘛）

```
【一句话概括】      ← 这一节到底在解决什么问题
```

### 3. 三条学习铁律

| 铁律 | 为什么 |
|---|---|
| **代码必须自己敲一遍** | 看懂了 ≠ 会写。看懂是别人的，敲出来才是你的 |
| **画图** | 链表、树、图，光看代码想不明白。拿笔画箭头，箭头画对了代码就通了 |
| **先做自测再看答案** | 看完答案觉得"我会了"是错觉，做题时卡住的地方才是你真正没懂的地方 |

### 4. 环境准备（5 分钟搞定）

笔记里的代码是 C++（教材用 C++ 描述）。你只需要一个编译器：

**Windows（推荐 Dev-C++ 或 VS Code + MinGW）**
- 最简单：下载 **Dev-C++**，安装后直接写 `.cpp` 文件按 F11 编译运行。
- 更专业：装 **VS Code** + 扩展 `C/C++`，再装 MinGW-w64 编译器。

**验证装好了没**，打开命令行（Git Bash / CMD）输入：

```bash
g++ --version
```

看到版本号（如 `g++ (Rev6, Built by MSYS2 project) 16.1.0`）就成功了。
**版本号不必和上面完全一样**，只要能看到一串版本数字，且不低于 `4.8`，就够用了。

> 注意：本笔记代码文件夹（`code\`）里都是 `.cpp` 文件，用 `g++` 编译即可。
> 如果你以后遇到 `.c` 文件（纯 C 代码），**也用 `g++` 编译没问题**——g++ 两种都能编。

## 四、小白避坑总纲（跨章节通用）

这 8 个坑，几乎每个初学者都会踩。先看一遍，踩到时回来复习：

1. **数组下标从 0 开始**。`a[0]` 是第一个元素，`a[n-1]` 是最后一个。课本里说的"第 i 个元素"经常指 `a[i-1]`，一定要看清题目约定。

2. **`->` 和 `.` 别搞混**。`p->next` 用于**指针**，`s.next` 用于**对象/结构体本身**。
   ```cpp
   Node* p = new Node;   // p 是指针
   p->data = 1;          // 指针用 ->
   Node  s;              // s 是对象
   s.data = 1;           // 对象用 .
   ```

3. **动态内存申请了要释放**。`new` 配 `delete`，`new[]` 配 `delete[]`。不配对就是内存泄漏。

4. **删除链表节点，顺序不能反**。必须先保存后继，再删：
   ```cpp
   Node* q = p->next;   // ① 先记住要删的
   p->next = q->next;   // ② 把它摘下来
   delete q;            // ③ 再释放
   ```
   反过来先 `delete` 就找不到后继了。

5. **递归必须有出口**。每个递归函数第一件事就是写 `if (结束条件) return ...;`，否则栈溢出崩溃。

6. **循环队列的"空"和"满"会长得一样**。所以要少用一个空间，或者加个计数器。这是第 3 章的重点。

7. **大 O 只看最高阶项**。`3n² + 5n + 100` 就是 `O(n²)`，常数系数和低阶项都扔掉。

8. **树/图的遍历一定要标记"已访问"**。否则会绕圈跑到死（第 5 章的 BFS/DFS 尤其致命）。

## 五、遇到卡住怎么办

按这个顺序试，通常 10 分钟内能解决：

1. **把数据结构画出来**（链表画箭头，树画圆圈，图画连线）——90% 的"想不通"是没画图。
2. **用小数据手算一遍**（3 个元素的链表、2 层高的树），在纸上模拟代码每一步。
3. **打印中间结果**：在关键位置加 `cout << "现在 p 指向：" << p->data << endl;`
4. **回看上一章的"C/C++ 知识回顾"**——很多卡点是语法没记牢，不是算法难。
5. **确认是"看不懂"还是"写不出"**：看不懂就回看类比和图；写不出就照着代码敲一遍再默写。
